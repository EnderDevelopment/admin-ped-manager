# AdminPedManager

AdminPedManager is a FiveM resource that allows administrators and owners to add peds with inventory and stash functionality anywhere in the game. This resource is designed for use with the QB-Core framework and provides a simple way to manage peds and their associated inventories.

## Install

1. Download the latest version of AdminPedManager from the GitHub repository.
2. Extract the contents of the zip file into your FiveM server's resources folder.
3. Add `ensure AdminPedManager` to your server.cfg file to start the resource automatically when the server boots up.

## Use

1. Connect to your FiveM server with a client that has admin or owner permissions.
2. Use the command `/addped <model> <stash>` to add a ped with the specified model and stash name. For example, `/addped a_m_m_beach_01 pedstash1` will add a beach ped with the stash name "pedstash1".
3. Interact with the ped to open the associated stash inventory.
